# One-Line Office Jokes

[![make.fun](https://make.fun/badge/u-markk-st-one-line-office-jokes-a51f2bcc.svg)](https://make.fun)

## About

One single line that makes office life funny, written for [make.fun](https://make.fun)'s "One-Line Office Jokes" bounty.

The entry program (`main.ts`) writes the joke to `/output/entry.txt`:

> The printer jammed, so I emailed IT — and IT replied-all to the whole company asking if anyone else's printer is jammed.

Two real details of office life in one line: the printer that jams at the worst moment, and the reply-all. The laugh lands in the last few words — IT answers a one-person problem by emailing the entire company about it.

## Run

```sh
node main.ts
```

Deterministic, no network: it always writes the same 120-character line to `/output/entry.txt`.
